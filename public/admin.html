➕ إضافة سؤال جديد

💳 الدفع بالفيزا (Stripe)

عند تفعيل Stripe: العميل يدفع بالبطاقة → البطاقات تُفعَّل تلقائياً في حسابه (باقات فردية). المفتاح السري يُضبط في Firebase Functions — لا تضعه هنا.

إعداد Firebase (مرة واحدة):
1. أنشئ حساب Stripe
2. في Terminal:
firebase functions:config:set stripe.secret_key="sk_..." stripe.webhook_secret="whsec_..." app.origin="https://teleplay.online" 3. في Stripe → Webhooks → أضف:
https://us-central1-four-fruits-fun.cloudfunctions.net/stripeWebhook
4. Events: checkout.session.completed
5. firebase deploy --only functions

🇪🇬 Paymob — مصر (فيزا · محفظة)

وضع الاختبار (Test): يمكنك الربط والتجربة الآن — لا يلزم انتظار تفعيل Live. بعد الدفع التجريبي تُفعَّل البطاقات تلقائياً في /my.

أرقام فقط — من Paymob → تكاملات الدفع → Card → Integration ID. ليس Transaction ID.

مفتاح طويل يبدأ بـ egy_pk_test_ — من Paymob → API Keys → Public key

يُستخدم فقط لو عملة الطلب ≠ عملة Paymob (مثلاً USD → EGP)

الأسرار (Secret + HMAC): في ملف functions/.env.four-fruits-fun ثم:
firebase deploy --only functions Webhook (Transaction Processed) — الصق في Paymob:
https://us-central1-four-fruits-fun.cloudfunctions.net/paymobWebhook

🎁 وضع "باقة واحدة"

لما تفعّل الخيار ده، الصفحة الرئيسية بتعرض باقة واحدة بس (الباقة المميّزة). الباقات التانية بتفضل موجودة في قاعدة البيانات — بس مش هتظهر للزوار. الأكواد التسويقية هي طريقة الترويج والخصومات.

👥 المسوّقون (Affiliates)

أضف المؤثرين والمسوّقين هنا، وبعدين اربطهم بأكواد الخصم في القسم اللي بعده. كل مسوّق ليه رصيد عمولات معلّقة (المستحق) ورصيد مصروف (تم دفعه).
